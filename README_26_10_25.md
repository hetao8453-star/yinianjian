# 一念间 · Android 验证版 v4（2026-10-26）

这是自用验证包，不是公开发布版本。包名仍是 `com.intentpause.app`，显示名改为“一念间”，可以直接覆盖升级旧验证包（同一台机器构建的 debug 签名）。

## 这一版改了什么

- **名称与图标**：产品名改为“一念间”，小绿团子叫“小缓”；用你提供的图做了自适应图标、圆形图标和各密度图标。
- **首次介绍页**：第一次打开先看一页介绍，只讲“是什么、在哪用、数据在哪”，文案是“打开之前，想想这次。”；之后不再出现。
- **确认页第 1 页**：顶部增加明确的关闭“×”；“应急使用 3 分钟”和“先不打开”改成可见的按钮，不再只是文字。
- **复查页可改时长**：继续时可选 3 / 10 / 30 分钟或自定义 1–180 分钟，不再固定沿用原时长。
- **自定义时长输入**：输入框获得焦点时会自动滚动到可见位置，减少键盘遮挡。
- **敏感应用**：新增“我的 → 敏感应用”，勾选后这些应用打开时不弹确认页、也不记录（适合银行、密码、支付类）。
- **常驻后台保护**：新增轻量前台服务，降低被系统清理的概率；通知权限不请求也可以运行，但系统可能不显示那条常驻通知（到时提醒仍然由无障碍覆盖层完成，不依赖通知）。
- **记录页降密度**：统计卡下增加口径说明；“一周节奏 / 时间花在哪”收进“趋势”，默认折叠。
- **文字精简**：首页、确认页、复查页、我的、记录页的主要文案改短；权限说明保留必要解释。
- **无障碍自动跳转**：启动时如果检测到无障碍未开启，会跳到系统无障碍设置；同时改为读取系统设置判断，避免刚开启时误跳。
- **计时**：继续使用按所选分钟数计算；短暂切换不取消计时；3 分钟中途 Home 5 秒再返回已验证仍会复查。
- **其他**：仍保留取消监测二次确认、每应用默认时长、3/10/30 + 自定义、状态栏覆盖、记录页无“最近会话”。

## 权限与通知

| 能力 | 用途 | 是否必需 |
|---|---|---|
| 无障碍服务 | 知道你选的应用何时进入前台，显示确认页 | 必需，系统设置手动开启 |
| 前台服务 | 降低被系统清理概率 | 可选，自动启动 |
| 通知 | 前台服务的常驻通知、兜底提醒、开机提示 | 可选；拒绝后前台服务仍尽量运行，但通知可能不显示 |
| 开机广播 | 开机后检查服务状态、清理失效计时 | 建议 |
| 电池优化白名单 | 减少 iQOO 后台清理 | 可选 |
| 自启动/后台高耗电 | 厂商设置，不是权限 | 建议手动允许 |

不申请：联网、读取屏幕内容、使用情况访问、普通悬浮窗、存储、通知读取等。统计只基于本应用观察到的窗口切换；敏感应用完全不记录。

## 安装与升级

1. 安装 `deliverables/一念间_v4_26_10_26.apk`；签名不一致时先卸载旧包（会清掉旧选择）。
2. 安装新包后 Android 可能关闭无障碍，需要重新开启一次“一念间 · 应用使用提示”。
3. 首次打开会看到介绍页；之后照常使用。
4. 如果系统提示“受限设置”，到应用信息页允许受限设置后再开无障碍。

## 已知边界（未在 iQOO 12 上验证）

- 确认页在目标应用进入前台后盖上去，不是“真正启动前拦截”。
- 状态栏被确认页覆盖后，确认页期间看不到系统时间/电量；若想保留需另做图标适配。
- 游戏/广告抢界面只做了 300ms 延迟隐藏，没有完全消除。
- 前台服务不请求通知权限，常驻通知可能不可见；这不是到时提醒失败的原因。
- 服务被强制停止或厂商清理后，无障碍仍需手动重开；App 不能自己开。
- 记录与统计只覆盖服务运行期间、受控应用；不是系统级使用时长。
- “少用时间”是估算：只统计复查页选择“现在离开”的会话。
- 深色模式、超大字号、横屏、分屏、TalkBack 未系统适配。
