# 意图提醒 · Android 真机验证版

这是 Android 版的首个可安装验证包。界面名称暂用“意图提醒”，产品正式名称还未确定。

## 已实现

- 在手机已安装、带启动入口的应用中搜索并勾选需要提醒的应用。
- 选中应用进入前台时显示目的确认：查找内容、回复消息、放松一下、还没想清楚。具体目标可选填；不评价理由好坏。
- 选择 5、10 或 20 分钟；默认 10 分钟。到时如果该应用仍在前台且屏幕亮着，显示复查页。
- 离开目标应用不超过 1 分钟再回来，沿用原计时；超过 1 分钟重新确认。
- 可应急放行 1 分钟，到时仍在用则复查；本机只保存应急次数。
- 复查时可继续、换目的或离开。点击离开回到桌面。

## 首次在手机上试用

1. 安装调试 APK。手机可能要求允许这次安装来源；只从自己电脑复制这个测试包。
2. 打开“意图提醒”，勾选一个用于测试的应用。
3. 点击“开启应用使用提醒”，在 Android 无障碍设置中启用“意图提醒 · 应用使用提示”。Android 对侧载应用可能先要求在应用信息页允许“受限设置”，具体取决于手机系统。
4. 打开测试应用，检查目的页；分别试放松、离开、应急和到时复查。
5. 测试后可在系统无障碍设置中关闭服务。

## 尚待真机核验和完善

- iQOO 12 / Android 16 上的前台事件、弹层显示、横屏视频、键盘输入和锁屏恢复表现。
- 微信读书等阅读应用的低打扰鼓励。
- 系统杀死服务后的会话恢复、分屏/画中画、多窗口、通知快捷回复。
- 视觉细节、深色模式、TalkBack、超大字号和正式分发签名。

这个版本由无障碍服务监听应用窗口切换，仅取应用包名；不读取屏幕内容。确认页是在目标应用进入前台后盖上去，不能保证在应用任何内容显示前拦截。
