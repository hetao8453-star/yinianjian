# 慢一拍 · Android 验证版 v2（2026-10-25）

这是自用验证包，不是公开发布版本。包名仍是 `com.intentpause.app`，显示名称改为“慢一拍”，可以直接覆盖升级 v1 验证包（同一台机器构建的 debug 签名）。

## 这一版改了什么

- 确认流程拆成两页：目的页（查找内容 / 回复消息 / 放松一下 / 还没想清楚 + 应急使用 3 分钟）→ 时长页（5 / 10 / 20，默认 10，点选即进入）。不再出现“选时长后跳回页面顶部”。
- 修复确认页文字框不能输入的问题：输入法窗口事件不再被误判为“切换到了别的应用”，覆盖层不会被输入法顶掉；已在 Android 16 模拟器上确认可以弹键盘并输入。
- 应急使用从 1 分钟改为 3 分钟；到时仍在应用内会复查。
- 底部三个 Tab：首页 / 记录 / 我的。
- 首页只显示“已控制的应用”（默认 3 个，可展开）；添加应用进入独立选择页，支持搜索、已选优先、分批加载。
- “记录”页：月历热力图、选中日统计、当日分应用明细、一点感受、一周节奏、时间占比环形图、最近会话。
- “我的”页：无障碍/通知/电池优化/自启动状态，全部记录（按应用 → 每次会话的目的、备注、时长、提醒、继续、离开），权限说明，运行记录（排错用）。
- 新增本地通知（可选）：确认页无法显示时的兜底、开机后发现无障碍被关闭时提示一次。
- 新增开机检查、电池优化入口、iQOO/OriginOS 自启动与后台设置指引。
- 新增本地 SQLite 记录：会话、每次选择、每日感悟、服务连接/断开。全部只存本机。

## 权限说明

| 能力 | 用途 | 是否必需 |
|---|---|---|
| 无障碍服务 | 知道你选的应用何时进入前台，显示确认页 | 必需，系统设置手动开启 |
| 通知 | 兜底提醒、开机状态提示 | 可选 |
| 开机广播 | 开机后检查服务状态、清理失效计时 | 建议 |
| 电池优化白名单 | 减少 iQOO 后台清理停掉服务 | 可选 |
| 自启动/后台高耗电 | 厂商设置，不是权限，需要手动允许 | 建议 |

不申请：联网、读取屏幕内容、使用情况访问、普通悬浮窗、存储、通知读取等。统计只基于慢一拍自己观察到的窗口切换。

## 安装与升级

1. 用 Android Studio 或 `adb install -r` 安装 `deliverables/慢一拍_v2_26_10_25.apk`。
2. 如果系统提示签名不一致，需要先卸载旧验证包（会清掉旧选择），再安装。
3. 安装新包后，Android 可能关闭无障碍服务，需要到系统设置重新开启“慢一拍 · 应用使用提示”——这是侧载应用的系统限制，不是应用在反复申请权限。
4. 首次进入“我的 → 运行状态”按需开启通知、电池优化，并按“权限说明”里的 iQOO 步骤允许自启动/后台高耗电、锁定最近任务卡片。

## 已知边界（未在 iQOO 12 上验证）

- 确认页是在目标应用进入前台后盖上去的，不是“真正启动前拦截”。
- 输入法修复已在 Android 16 模拟器验证；iQOO 自带输入法、横屏、分屏、画中画、锁屏恢复仍需真机验证。
- 服务被系统杀死或重启后的会话恢复已做持久化，但恢复表现未真机验证。
- 记录与统计只覆盖本应用服务运行期间观察到的受控应用；不是系统级使用时长。
- “少用时间”是估算：只统计复查页选择“现在离开”的会话，按当时本可继续的时长累加。
- 当前图标是代码绘制的临时原创小绿豆；AI 图标待生成后替换（见 `图标提示词_26_10_25.md`）。
- 深色模式、超大字号、TalkBack 未系统适配。
